COMO INSTALAR
1. No repositório GitHub, publica os ficheiros e pastas do ZIP preservando os caminhos.
2. Em Settings > Actions > General, permite que GitHub Actions escreva no repositório (Read and write permissions), se necessário.
3. Em Actions, executa manualmente "Atualizar resultados oficiais TSE" para testar.
4. O agendamento GitHub Actions solicita atualização aproximadamente de 5 em 5 minutos. Pode sofrer atrasos; não é um serviço de baixa latência garantida.
5. O site verifica results.json a cada 30 segundos; o GitHub Pages pode demorar a publicar.
6. Se houver erro de rede, esquema ou inconsistência, o script falha sem publicar novos dados.
7. NÃO publiques CENTRAL_MANUAL_RESERVA_PC.html. Está apenas para contingência e gera ficheiros manuais que não devem ser misturados com o fluxo automático.
